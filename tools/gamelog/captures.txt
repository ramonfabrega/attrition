# captures.txt — the capture queue as a file (docs/QUEUE.md item 90,
# docs/DECISIONS.md entry 27).
#
# One stanza per capture, `key: value`, blank line between stanzas, `#` for a
# comment. Every key is a `longtrace.sh` input — the script's four positional
# arguments and the environment hooks documented in its header — so a stanza
# is a capture and nothing else needs writing to run one. `runqueue.sh` walks
# this file top to bottom, **one capture at a time**, and skips any stanza
# whose archive already exists, so it is re-runnable and a crash costs the
# capture in flight rather than the queue.
#
#   run:        the run number, and the archive's name
#   tag:        the archive's suffix
#   item:       the queue item this capture is owed to
#   why:        one line, for the run section this becomes in docs/ORACLE.md
#   frames:     the `!quit` frame
#   mapstyle:   14 Great Lakes, 18 East Indies
#   cfg:        the `-config` argument; `-` means none, and absent means the
#               default (`-config check.ini` on 14, none elsewhere)
#   end:        `[End Frame]` detail, setlog.py's `end:` list
#   start:      `[Start Game]` detail, setlog.py's `start:` list
#   dump_all:   DUMP_ALL, default 0
#   window:     "LO HI" for a DUMP_ALL window instead of the cheap dump
#   cover:      rontrace.cfg's body, default `cover=1`
#   cmd:        one `rontrace.cmd` line, repeatable, in file order
#   driver:     a script driven while the game runs, for the right-clicks the
#               cheat channel cannot issue — `move` is a teleport and **no
#               console command issues an order at all**
#   settle_min: bytes below which the poll loop will not call a run finished
#   check:      a command run after the capture, from the repo root, to say
#               whether it landed; repeatable, and a non-zero exit is loud
#
# The order is the charter's: 108 first because it is the cheapest and fully
# specified, and it proves the pipeline before anything costly rides on it.
#
# **Run numbers start at 42.** 40 and 41 are taken — two undocumented
# `census` captures from 2026-08-30 that no run section in `docs/ORACLE.md`
# mentions. `longtrace.sh` archives its trace as `rontrace-run$N.log`
# unconditionally, so re-using a number silently overwrites another run's
# trace while leaving its gamelog in place, which is the worst of both. Check
# the Logs directory, not the documents, before picking a number.

# `Guy::do_turn@005d97a0:15` swaps the standing walk for CHAR_TURN_LEFT/RIGHT
# on a guy whose piece names a turn, and no guy in any capture on disk carries
# the bit. The reading that makes this stageable is **which** call fires the
# override: `Unit::move_step` passes 1 only on its two turn-in-place branches,
# but `Guy::move:109` calls `turn_towards(this, des_angle, _, 1)` — and
# `turn_towards` passes that straight through to `do_turn` — on the standing
# arm, guarded only by `guy_flags & 2`, which every dumped guy has clear. So a
# turner unit **turning towards a target in a fight** fires it, which is far
# easier to stage than a 180-degree walk.
