## Summary

**Counts by ruling (10):** twin 1 · twin-differs 3 · absorbed 1 · ui 3 · dead 1 · replaced 1 · **unmodelled 0**.

- twin: `FarmsData::get_farm_type`.
- twin-differs: `CityData::get_empty_trade_routes` (owner dropped from the pair match; bit 0 also required; `1 − count` read `!= 0` makes a second route read free — all unreachable or uncaptured), `Farms::inc_time` (the original never reads `valid`, so a removed record whose object slot still answers `flags & 4` keeps drawing; inert on Great Sahara's nuke), `FarmsData::get_nearest_farm_type` (the `<=` tie already open in `docs/SYNC.md:489`; two unreachable arms).
- absorbed: `Farms::remove` (its `valid = 0` is the building's `alive` in the port; its ambience removal is art).
- ui: `build_box`, `Farms::recalc_heights`, `FarmsOut::get_name`.
- dead: `FarmsData::get_wheat_status` (no caller; its read is inlined into `do_gather` and ported as `farm_cell`).
- replaced: `Farms::walk_data`.

**The rubric, not the census, is what holds most of this group open.** Four of the seven `layout` rows have a real twin whose doc comment already spells `Class::method` (`farms_inc_time`, `nearest_farm_type`, `farm_type`, `trade_pair_free`/`trade_route_exists`); `territory_kind` (`tools/census.py:1228`) demands `fn <snake(short)>` exactly, so a stem-prefixed or `get_`-less name falls to `layout`. **Proposed**: accept a `crates/sim` fn whose doc comment spells `Class::method` (or `Class::method@va`) under any name — it would move these four (three as `port` with their partings recorded, if partings are allowed in `port`). And `territory_kind` returns `layout` for a backed va (`:1227`) before the marks at `:1231–1236`, which is how `FarmsOut::get_name`, already `is_ui_body`, sits in the open count; **proposed**: the marks first.
