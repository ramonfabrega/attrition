## Rulings

- **A detached capture is waited on with `tools/gamelog/waitrun.sh`**
  (656). It blocks until `runqueue.sh`'s banner lands in the viadriver log
  — the file the banner actually goes to — or no runner is alive, and
  exits 0 / 1 / 2 on ok / FAILED / no banner. Made to fail first: a
  banner-less log with no runner exits 2, the case 571 sat in; ok and
  FAILED banners exit 0 and 1. Named in `CLAUDE.md`'s wait bullet,
  `viadriver.sh`'s header and `docs/ORACLE.md`.
- **The golden-line guard reads every pinned word** (638).
  `the_handoff_s_golden_line_is_the_pinned_word` is a verdict function
  over a table of eleven names — `ch1`–`ch8`, `restage`, `ch7b`,
  `ch7b-control` — and, with nothing open, requires the line to lead
  with `every chapter closed` rather than borrow `none pinned`. Made to
  fail first on the line that fooled it (`restage w792` over a closed
  constant), on a missing part, and on the borrowed phrase;
  `docs_guard::the_handoff_carries_the_golden_line` accepts the third
  form.
- **clippy and fmt run before the release suite, and the gate's last
  line names what it did not reach** (639). `steps_line` prints
  `Gate steps: N of 6 ran (…); not reached: …` in a `finally`. The order
  test was run against the old gate saved from HEAD first: a red suite
  left clippy unreached, exactly 617's case; and the two old tests that
  indexed the step list failed on the reorder before they were updated.
- **The memcap self-test's timeouts are 50 s, and the child's death is an
  elapsed assertion** (645): the child sleeps a minute and the wrapper
  must return inside forty seconds, whatever the load.
- **The receipt's `callwin` is read back from `rontrace.cfg`** (649),
  the file the tracer reads, as `rontrace.cmd` already was; tested on a
  cfg with and without the line.
- **`Block::fields_of(&[keys])` reads only the keys it names** (670), and
  `build_of` uses it for the `tx`/`ty` pairs. The coverage pin then
  failed first, as designed: fourteen `BUILDDATA` keys, printed and never
  read, that a whole-fields iteration had hidden since the pin was
  built. Pinned as unread with this item. The literal-0 half was fixed by
  661 and is covered by the standing clause.
