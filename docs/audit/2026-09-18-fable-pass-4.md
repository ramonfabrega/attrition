## Rulings

1. **A worker's gate runs every binary (item 339).** `release_gate.py`
   passes `--no-fail-fast`, copies the release run to
   `release-tests.log` in its report directory with no shell pipe between
   `memcap.sh` and the exit code, and prints a per-binary summary with
   every failed test's name (`test-summary.json`). On a word-moving item
   rondata is red by design on the two queue tests, and the sim suite —
   `no_float`, `soak`, `docs_guard` — had never run in a worker's gate;
   item 336 landed a red guard nobody saw that way. Made to fail first:
   the new test asserted the flag against the old command. A release that
   prints no `test result:` line is now an unobserved suite and fails.
2. **The queue race is the commander's own, and the guards stay on the
   working tree (item 318).** `the_handoff_s_scoreboard_is_the_floors`
   reads `CARGO_MANIFEST_DIR/../../docs/QUEUE.md` — the tree under test,
   which is right, since the gate runs before the commit that would be
   the alternative source. A worker's tree cannot see the commander's
   rewrite except through `ccc update`. So the rule, not a code change:
   **nothing under `docs/` is edited while a gate runs**, the handoff is
   rewritten before the gate and not during it, and a worker never
   updates mid-gate. It is a clause in the commander's chain below.
3. **The commander's chain lives in `CLAUDE.md`, not in memory (item
   345).** One paragraph in the fan-out rules: `ccc merge <ref> --no-ff`,
   the gate to a file, `ccc push <ref> --base`, `ccc rm <ref>`; never a
   raw `git merge`, never a hand-rolled reap; `ccc spawn --json`'s answer
   never filtered. DECISIONS 40 carries the rationale; the memory file
   becomes a pointer at it. Ramon's framing stands: memory is invisible
   and a rule nobody can read is not a rule.
4. **Width two may run a parked value-diff row beside the word's frame,
   never instead of it (item 330).** The third pass's rule — only what
   names a score books — was made against a wave that ran residue rows
   *instead of* the headline. With the headline lane occupied and a strict
   successor chain leaving the second lane idle, a parked row that names a
   dump field and a frame, needs no capture, and touches a module the
   headline item does not may be spawned from `docs/PARKED.md` directly.
   Its products park unless they name a score. At 31–39 USD a word-moving
   landing the marginal lane is cheap; whether it *paid* is the next
   pass's, from `lore spawns`, and the stop stays a doubling — **78** from
   today's 39.
5. **The commander counts its own landings and stops at twenty (item
   331).** The charter's trigger fired for nobody because nobody owned the
   count; the commander does now, and the handoff already carries it. At
   the twentieth landing since its boot the commander writes the handoff
   and ends its turn saying the pass is due — it cannot switch the model,
   so stopping is the whole act. Between, a free clear is taken at a
   **seam** — the successor chain gone cold, a map crossover — with `ccc
   clear <own ref> --then continue`, never mid-chain where the context
   that made the briefs cheap would be paid for again. The observability
   defect rides in ruling 3: seven landings of lineage were lost to a
   `grep` on a spawn's answer.
6. **The handoff's count of the Loop backlog is the mechanism, and it is
   now a guard (item 332).** `docs_guard::the_handoff_counts_the_loop_backlog`
   parses `Fable backlog: N Loop items` against the `(N) **` lines of the
   parked file's Loop section. It failed first on twelve against thirteen,
   which is the drift it exists for. No separate steering queue: the
   parked file's section is the queue, and the count is its opener.
