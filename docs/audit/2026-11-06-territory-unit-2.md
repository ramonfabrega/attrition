took a doc comment's `Class::method@va` on any fn.

  `docs/AI.md` §383 already scans the image this way): `UnitData::activity_type@00608210`,

  `ObjectData@006452f0` and `WallData@0063fa30` overloads, slot `+0x140` having no object

  `UnitData::attack`, `Unit::process_healing` — but it lets a SEAM saying "not carried" be read as
  `ctw` rather than as an open rule.
