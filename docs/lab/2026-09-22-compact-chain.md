# L83: compact replay of the validated continuation chain

The L82 experiment now has a reusable local fixture: 597,820 bytes, excluding
its verification report and the separately required owned executable. A fresh
process reproduced the complete experiment in 14.86 seconds without reading
the broad captures or discovering dependencies. No capture was needed, no main
score moved, and draft PR #6 remains frozen.

## What is retained and checked

`tools/explore/compact_chain.py build` validates the L81 source pair and packet
projections, prepares the first call, runs the complete L82 experiment, and
serializes initial region inputs. It then reloads the fixture and requires
exact baseline fingerprint and complete experiment equality before removing
its incomplete marker. Failed builds remain unusable.

There are 576 declared regions and 254,596 packed input bytes. The fixture
also retains both prefix/context/post-state sidecars, source payload and trace
hashes, model parameters, region metadata and golden results. Code comes from
the hash-pinned original executable; modeled service code, allocator storage
and thread setup are regenerated by the existing constructors. Neither original
code nor captured game data enters Git.

Serialization uses each region's initial data, never the emulator's live final
memory. Read/write permissions, executable identity, undefined scratch bytes,
logical borrowed extents and cumulative model quotas survive the round trip.
Loading rejects damaged files, unsupported quotas, missing code, malformed
extents, duplicated names and trailing bytes. Replay does no dependency search
and has no fallback to the source capture.

The exact comparison includes L82's frozen negative control, original caller
instruction transition, native boundary comparisons, repeated-chain fingerprints
and baseline restoration. This is stronger than comparing the displayed path
alone. It preserves L82's explicit path-pointer relocation allowance.

## Measurements and controls

The initial build's preparation counter was 86.80 seconds; its internal cold
verification took 14.95 seconds. Preparation excludes the experiment callback,
so these are not total build time or a valid whole-experiment speedup ratio.
The tool now records preparation and total build durations separately. L82's
98.07-second statement has been corrected in place for the same timing issue.

A separate process intercepted Python file opens and refused the entire lab
capture directory. Its deliberate forbidden read failed; subsequent replay
opened only the fixture and owned executable, made zero capture accesses, and
matched the entire reference in 14.86 seconds. This is a controlled reader-path
check, not an operating-system sandbox claim.

Temporary fixture copies provided three negative controls:

- An incomplete marker refused before loading.
- A changed packed input byte failed its file hash.
- Removing the modes region and updating its manifest/hash consistently still
  failed at the undeclared access. Metadata integrity cannot supply missing
  execution dependencies.

The focused suite passes 63 tests with the owned image. Authored controls also
show that a live mutated counter reloads from its initial value, undefined
scratch remains unreadable, and read-only storage stays unwritable. The full
release gate passes 1,203 tests, 782 fixture requests with none missing, clippy,
formatting, the install survey and paperwork checks.

## Reproduction and limits

Use the existing cached Unicorn environment, with `PYTHONPATH=tools/explore`:

```sh
uv run --offline --with unicorn==2.1.4 python tools/explore/compact_chain.py replay \
  /Users/rf-studio/code/fun/attrition/game \
  /Users/rf-studio/ron-data/lab-experiments/2026-09-22-compact-chain/fixture
```

To rebuild, use `build INSTALL FRESH_OUTSIDE_REPO_DIRECTORY --capture-root`
with the L81 `2026-09-22-second-return-modes` capture root. Builds reject a
repository destination before reading source inputs. Evidence is retained
outside Git under `2026-09-22-compact-chain` in the lab-experiments directory.

This is a trusted local derived cache, not signed evidence or a new native
witness. Replay checks retained hashes and golden results; it does not
revalidate absent broad captures. Coordinated malicious metadata replacement
is outside this contract. Addresses remain tied to this capture and model;
this is not a universal or provably minimal fixture format. Extended CPU state
is still not imported. Internal execution and intervening world advancement
remain unproved, as L82 explains.

The next useful use is a concrete divergence falsifier selected by steering.
The compact fixture makes repeated local experiments cheaper; it does not
justify expanding simulation claims or collecting another capture by itself.
