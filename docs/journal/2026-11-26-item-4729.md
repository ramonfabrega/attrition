## How a slot is drawn: the value diff

`IFaceButton::on_redraw@007fc730` handles both kinds of slot:

- **An option slot** (`IFACEBUTTON_OPTION`) uses `IFACEBUTTONDATA`'s `tex`, which is `TEX_ORDERS_0`
  (`art\iface_unit_orders.tga`) (0, 0) 61 × 39. It is moved by `(w + 1)·tex_col`, `(h + 1)·tex_row`, so the crop is
  at (62·col, 40·row).
- **A type slot** (`IFACEBUTTON_UNIT`, `_BUILDING`) uses the type's own `TEX_ID`, `TEX_COL` and `TEX_ROW`, on the same
  grid. The Citizen's is `TEX_UNITS_0` (`iface_units_01.tga`) col 4 row 0 (`unit_graphics.xml`,
  `CITIZENS-DEFAULT-AGE0`). Large City's is `TEX_BUILDINGS_1` (`iface_buildings_civic.tga`) col 2 row 3
  (`buildingrules.xml`). `setup_button@00817010` makes a type in the building range `IFACEBUTTON_BUILDING`.
- **A disabled button** has its texture rectangle moved by (−1, −1) (the listing's four `+ -1` under
  `!is_enabled`), and it takes overlay 1 rather than 0.
- **The overlay**, `IFACEBUTTONCLASS`'s `def_overlay_texs0` or `def_overlay_texs1`, is `TEX_COMMON`
  (`iface_ALLCIVS_assets.tga`) (364, 0) or (364, 40), 61 × 39. It is a 2-pixel frame (alpha 255 on 384 pixels, 0 on
  the 1,995 inside). It goes on top at `this->color` × `0x80/0xff` when enabled and × `0x40/0xff` when disabled.
