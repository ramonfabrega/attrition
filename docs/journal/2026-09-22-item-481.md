## The defect was a brace

`do_move@005f7b30:207` is `if (ptype->max_range != 0) {`, and the brace
closes **after** the captain retarget at `005f803f`. §37.2 says so in
prose — "Inside `do_move`'s `ptype->max_range != 0` gate" — and the Rust
wrote it as a conjunct of the arm above:

```rust

    && self.is_in_range_at_margin(me, at, t, margin) { … }   // the kill
```
