## The turns

`Options::exec@0072c4b0`, the `(option, object, int)` wrapper, is entered on the options object, and `mode` and
`mode_data` are read back after the frame returns.

1. **The first run stopped at `GetKeyState`.** `step4.py` now answers 0 to it, stdcall with one argument: no
   modifier held.
2. **Cases 0 to 2 read the console's selection.** The packet's own selection (play 0's group) holds the capital,
   0/2000. With it, a page button leaves the mode unchanged, which is the instrument's red half.
   - The harness pokes that group to the slot's first citizen: `num` 1, `buildings` 0, `who`, `list[0]`.
   - Its address is the one the listing reads: `imul $0x9f0, 0x2a0(%eax)` and `add 0xe8d444`, which is
     `select_groups+0x14`. Ghidra's `select_list._padding_` did not say which word.
3. **The page count**: `Game::semaphore` is an inline `BitMask<256>` at `+0x814`, its bytes at `+0xc`. Byte 2's
   bit 2 is cleared and set, so 21 runs a packet.
4. **Every run returned, and every one agrees with §32.7's reading.** Under two pages `OPTION_BUILD_WONDER`
   leaves the standard panel, and NEXT and BACK wrap modulo 2.

The `Event::Page` arm's arithmetic is now `turn(option, page, n)`, and the arm calls it. The test reads the TSVs
into it row by row.

  (`pages-turns`).
