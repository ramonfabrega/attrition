## Step 1: the probe is a tool

`rondata::diff::held_probe` is a new file (on `ledger.rs`'s `NOT_A_DIFFER`). Every leader-record comparison site calls
`held_probe::rows(run, block, who, &mine, &theirs)`, or `held_probe::map` where ours is keyed by name. There are
sixteen calls: `harness.rs` two (`widen_walk`, `widen_east_indies_walk`), `golden.rs` two, `golden/cases_01_09.rs`
two, `harness/tests/cases_02.rs` two, `cases_03.rs` three, `cases_04.rs` three, `SeatWalk::compare_part`
(`gunpowder_melee.rs`) and `diplomacy_take::walk_take_from`.

- `RON_HELD_PROBE=<leaf,leaf,…>` switches it on. The variable is read once into a `OnceLock`; off, a call returns at
  that read. `RON_HELD_PROBE_FILE=<path>` sends the output to a file, otherwise it goes to stderr.
- `HELD <test> <run> <file:line> block <n> who <w> <cell> ours <v> theirs <y>` is written as found. Here `<test>` is
  the libtest thread's name and `<run>` is the capture name where the site knows it, else `-`.
- `SEEN … who <w> <cell> theirs <y> rows <count> blocks <first>..<last>` is counted per thread (theirs non-zero
  and agreeing) and written when the thread ends.
- `RON_HELD_PROBE_BEND=<cell>` adds 1 to ours on that cell inside the probe only. The site's own comparison is
  untouched.

**Red, on purpose.** With `RON_HELD_PROBE_BEND='hire_who[1]'` over `run1575_s_declarations_are_ours`, the probe wrote
**765 `HELD` rows**, the bent cell on every record (255 blocks × 3 leaders), e.g. `HELD
run1575_s_declarations_are_ours - diplomacy_take.rs:193 block 896 who 0 hire_who[1] ours 0 theirs -1`. Every other
`hire_who` cell was `SEEN` at −1, 255 rows each. The unit test `held_probe::tests::a_bent_cell_is_held` holds the same
judgement offline.
