## The reading, before the staging

The brief's premise was that the cheat's block in `Unit::think` decides
something for a computer's civilians. The decompile and two dumps already
on disk said it cannot:

- `Unit::init@00612100:585` sets `unit_masks |= 0x40000` whenever
  `(leader_flags & 0xc) != 4`. That holds for who=1 (`0x03000013`), so
  every computer unit carries the bit. run141's who=1 units print 262152
  and 262154 on 700, and run146's cheat-`add`ed who=1 hoplites print
  331790.
- For who=1 bit 4 is clear, so `think:206` is entered only with `ai_off`.
  Its arms need bit 4, and its one exit (`:264`, `0x40000` clear → return)
  is false for every unit of who=1. The tail runs as without the cheat.
- `think_peasant` is above the block anyway. For an AI-driven unit its
  wait is `idle >= 1`, so the citizen should gather on its first think,
  not on ~763.

`chapter7b.cmd` says all of that and names the frame and record where
each falsifier fires. It was committed as `4fa528f` before the run. The
commander ruled to capture anyway: a reading that predicts a falsifier is
exactly where a cheap run should settle it.
