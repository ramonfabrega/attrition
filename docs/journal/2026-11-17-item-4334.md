hook on `make_options@BuildOut`. A citizen's build page is `UnitOut::make_options@00615fc0` in `BUILD_OPTIONS`

An oracle needs:

- the entry `0x615fc0`, `this` each citizen: type `0x32`, `0x33`, or `is_peasant`;
- `MiscAccess::options`, a pointer at `0xc06204` in the map, poked `+0x74` = 1 (`BUILD_OPTIONS`, the PDB's
  `OptionMode`);
