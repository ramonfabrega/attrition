- **East Indies** (`MAP_STYLE` 18) uses Great Lakes' calls in Great Lakes' order. Only three things differ: the mask
  (`MapEastIndies::make_continents@00697540`), the file and the style id `place_all` reads. `docs/MAPGEN.md` §15 had
  already checked every one of its phases on the passes Great Lakes' built.
- **Great Sahara** (`MAP_STYLE` 7) uses the whole-land mask (`great_sahara_make_continents`, on the stream itself). It
  then runs `Terrain::init` without heights, the rivers, and the heights on the grid the rivers left
  (`map_heights::heights`), in the order `mapgen`'s Great Sahara tests walk them (items 3809, 3811, 3812).

**One predicate was wrong for Great Sahara.** `tileset_draw` refused to draw on a style with fewer than two
`TILECHANCE` entries. `Map::init_map_data@0069f250` gates on the chances' sum alone (`if (T − 1 < 1)` no draw), so
SAHARA.xml's one `GS_Desert` 100 draws. The gate is now the sum. Great Lakes and East Indies each list several
tilesets, so this predicate never decided anything for them.

`from_lobby` dispatches on `Style::of(MAP_STYLE)`. Every composed style randomises its starts, because only East
Meets West's `make_continents` writes `randomize_starts` again.
