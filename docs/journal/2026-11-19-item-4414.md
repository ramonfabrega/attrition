## For the Loop

The units emitter's `_ => {}` arm still hands over only the type and node
byte for every order kind whose walker is not ported (`docs/CHECKSUM.md`
§17). `THINK` was one such kind, and only a range diff showed it. A kind
whose walker is the base's flags byte is a one-line arm. The vtables that
name `UnitOrder::walk_data` at `+0x8` are `UnitOrder`'s and
`ThinkOrder`'s alone.
