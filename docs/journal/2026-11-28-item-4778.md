## The reading

`Wall::close@0063f6e0:79` calls `start_me(this, 0)` on every close. `Wall::start_me@0063d790`, for each footprint
tile:

- `param_1 != 0` (placement): `|= 0x80` when clear, else `|= 0x40`. Ours had this (`init_build`).
- `param_1 == 0`, `0x40` clear: `&= 0xff7f`.
- `param_1 == 0`, `0x40` set: `ObjectsData::find_building_placed_at@00658c80(x, y, −1, this->o, this->who)`. The
  tiles are cleared of both bits (`&= 0xff7f`, `&= 0xffbf`) only when it answers `< 0`. Otherwise the tile is left
  alone.

`find_building_placed_at`:

- **Gate**: the tile is `(mask & 3) == 3 || mask & 0x80`.
- **Search**: walks the objects chained in the nine cells round the tile.
- **Candidate test**:
  - its leader is below eight;
  - it is not `(param_4, param_5)`;
  - its leader is any one under `param_3 < 0`;
  - vslot `+0xc` answers. That slot is `is_build()` (`docs/DANGER.md`), so a started building counts too.
  - its tile corner and the type's sizes (`+0x234`, `+0x238`) cover the tile.

Ours cleared `PLACED | PLACED_TWICE` on every footprint tile unconditionally.

## The build

The `start_me(0)` arm of `close_building` is now `Sim::start_me_release`, which follows the listing tile by tile:

- `PLACED` only when `PLACED_TWICE` is clear;
- both only when `Sim::other_building_placed_at(t, b)` answers false.

That helper is the original's search as `start_me` asks it:

- the tile gate (`world::is_built_at`);
- any building alive, owner below eight, not `b`, covering the tile.

It is not `Sim::find_building_placed_at`, which takes one owner and a `!started` the original's `is_build()` does not
ask.
