## The harness

`diff::start::tests::every_lobby_s_start_built_from_its_choices` takes every lobby `lobby::lobbies_on_disk`
finds (161, asserted). For each, it reads every capture's setup prefix (`IndexedCapture::read_replay_setup`, never a
whole file) and picks the richest: cells first, then a setup trace, then objects. The other captures of that lobby are
lent through `borrow_from_siblings`. The richest is installed by `build_sim` and compared with `from_lobby` of its
`GAMEINFO` by `start_block`. `RON_START_LOBBY=n,…` with `RON_START_DIFF=1` (or `=all`) prints one lobby's steps,
notes and value diff. The whole run takes about 85 s in release on two threads.

It runs **§3's rules in both directions**. A field the installer cannot take from the dump is its own stand-in, so
a parting there is dropped and counted (`stand-in N` in the print):

- **owner 9**: a starting pasture's five, when no trace lends their seeds. No dump prints them, and the installer
  stands all five on the farm's centre with one type.
- **the sync word**: when no setup trace for the lobby is on disk.
- **a computer leader's personality**: when neither a trace bracket nor the start dump's own `PERSONALITY` block
  holds it. Where the block is printed (`LEADERS=9`), the installed side is set from it, so the built side is held to
  the original's numbers.

It also adds one record: **`FARM who/o farm_type`**, each farm against the dump's `FARMS` list. That is what backs
a pasture's existence.
