## The fix

`Sim::coll_move`'s one-block form returns when the cell's block is absent (`CollGrid::block_present`) as well as on
a region mismatch. Only `CollGrid::set` writes the bits, and a set always marks presence, so a cell without a block
holds no bit. The clear pass would have been a no-op there; only the set pass changes.
