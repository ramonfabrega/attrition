## The rule, as read

`Leader::set_diplo@006ec6a0(this, whom, level)`:
- It compares `this->diplos[whom]`, one direction only, with `level`. On a match it returns before every other step.
- On a change it does these in order:
  1. Leaving an alliance (old level 2) ejects each side's units from the other's and clears both `ally_mask` bits.
  2. Shows the third-party message.
  3. Stores the level both ways.
  4. Entering an alliance sets `ally_mask` and runs the victory test.
  5. Runs **`Armies::diplo_change(this->who)` on every level**, 0, 1 and 2: `this`'s armies, never `whom`'s.
  6. Sets `recalc_borders`.
- `diplo_change` then runs `Army::process(army, 1)` on each army in use. It skips a human, a dead leader and a
  flagged leader.
