## The reader, before the port

`rondata::mapgen::start_head` cuts a file just past its start `WORLD` block, which sits about 15 MB in, past
the `CONSTANTS`, and skips a file at its first `BEGIN` when the preamble carries no `World` line. The crate's
own `Log::parse`, `Log::initial` and `world_cells` read the cut. `gamelog::world_checksums_in` reads each
setup-trace record's sixteen `World` lines. `sim::mapgen::WCell::walked` packs a cell at its `types.txt`
widths.

- **The walked range is `[cell, cell + 0x15)`.** That is 21 bytes, `flags` through `was_seen`, read off
  `World::walk_data@006b5cf0`'s part-5 loop. It is not the 20 the queue's "0x00..0x14" could be read as.
- **496 of 496.** The packed grid's Adler-32 equals part 5 of every record from `setup.cpp` 1240 on, on 496 of
  496 traced files with a start grid. Item 3734 counted 337 on 2026-10-28. The archive has grown since then, and
  my criterion also takes a `DUMP_ALL` start grid. The sweep takes 3.3 s on four threads.
- **The count is a floor, not equality** (parked 3776b). Any file that parts fails the test. The file count only
  has to reach the pin, so a lane's new capture cannot turn it red.
