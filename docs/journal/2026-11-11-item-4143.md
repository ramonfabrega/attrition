## Stage 0: the values

**The selection's predicate**, read in `ground()` and not guessed, tests each pixel in this order:

1. one of our objects draws there;
2. it lies inside an object's bounding box plus 6;
3. it lies in an `INTERFACE` rectangle;
4. it lies in a `TRACED` polygon;
5. no terrain triangle covers it.

A pixel that passes all five is ground, and it belongs to the tile whose triangle is nearest. A tile scores when it
holds at least `HUE.min_pixels` (40) ground pixels. **No step drops a land kind by name.** So I split `ground()` into
`ground_why()`, which keeps each pixel's tile before the masks and the first mask that drops it. The new test
`what_the_ground_s_row_leaves_out` tallies every tile in view by its cell's kind: `WData.land`, the `COAST`,
`HALFLAND` and `ROCK` bits of `flags`, and a placed mountain. The test asserts that its scored set is `ground()`'s.

The table, pinned as `RUN1559B_3279_UNSCORED`:
