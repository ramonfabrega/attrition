## Why DIFFICULTY 4 and not 1

The brief said "a step harder". In single player, `LeaderData::get_diff` returns the lobby's `DIFFICULTY`
(`gamec->info.difficulty`). The per-player `diff 2` in the PLAYER blocks is `multi_diff`, which is read only under
multiplayer semaphores.

Every difficulty gate in `Leader::diplomacy` is one of `< 2`, `< 3`, `< 4`, `> 1`, `> 2` or `> 3`, so 1 behaves
exactly like 0 in the arm's predicates. A recon at 1 would have measured nothing about the leaf. The first value
that sets `aggression[k] = 1` before 7,000 is `> 3`, in the branch with one other live leader. That branch needs
`k` to be the human, so the reading predicted `aggression[0]` 1. The record says otherwise: the French come to it
only with the war on 6081, and the Russians never. So the reading of that branch is wrong, or it is reset after
it is set. One reading, not adjudicated.
