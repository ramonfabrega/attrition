**The dead scan and the residue, 252 rows.** The new mark is `census.unreferenced(exe, targets,
starts)`. It is the dead-scan of `tools/trace/report.py refs` (docs/EMULATOR.md §4), run over a
set and loading that file's `pe_sections`. It runs on every simulation function that the marks
leave open and that no replaced group takes. A target counts as live on any of:

- a `call`, `jmp` or `jcc rel32` from another function;
- a rel8 jump from another function;
- a four-byte copy of its address or RVA at any byte offset of any section but `.reloc`.

The scan confirms no site against the listing, so a word inside another instruction counts as a
reference. That can call a dead function live, never a live one dead. `blind::RESIDUE` is `dead`
as well: two readings ruled that no game this project can stage enters it. On the tip, the 827
rows scanned give 191 dead by the scan, and the residue adds 60 that the scan sees referenced, 251
in all. 147 of the 251 had been ruled `dead` by their reader; another 31 were ruled absorbed and 14
twin, the out-of-line copies of a body every caller inlines. A run of `--territory` now reads the
executable and exits, naming the path, without it.

On its first measurement the mark took 54 rows out of the replaced groups, 336 → 282. Among them
are the command manager's issuers, which the DLL calls by address (`blind.rs`'s own note on item
940), and the scan cannot see that. A replaced group is a design ruling, so the scan now skips

## What it does not establish

- **A class is a pattern the readings back, not a reading of every row it reaches.** It was run
  over every simulation function, and it reaches no row a reader did not read except
  `Farms::recalc_heights` (ruled `ui` in build-3, whose table spells its addresses in backticks).
  A function added to a class's namespace later is excluded unread.
- **The scan sees the image, not the DLL or a computed address.** A function called by address
  from outside the executable, or reached through an address computed at run time, reads dead.
  Replaced groups are exempt for the first reason. No open row is known to be reached either way.
- **§22 credits a walker on one frame of one game.** Arms that no state on frame 91 reaches are a
  reading: an order type other than the three the packet carries, a wall's own walk, a building's
  arms past the fifteen.
- **A spelling is the reader's ruling, not a diff,** as for 4039's 78 (Loop 3237's caveat stands).
- **The remaining open 576** is the work still left: layout 318, name 79, unmarked 179.
