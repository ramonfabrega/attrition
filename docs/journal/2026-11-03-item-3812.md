## What agrees (measured, first try)

**The generated grid is `(a · 7.5 + land_height) + b · 1.875`.**
- `a` is `Fractal(241, 241, smooth 5, flags 2, World.seed)`'s `get_height`,
  and `b` is the same fractal at smooth 3 with seed `2 · World.seed`.
- `land_height` is the global at 0xcbe54c. `Terrain::init` sets it to 30.0f;
  the decompile reads it as `__real_00000000`, a constant, which it is not.
- `flags & 2` makes `get_height` answer `h·100 >> 8`.
- In run1000's dump, 54,941 vertices agree with this to the bit, and so do
  the 98 mountain vertices below.

**The mountains.** `adjust_for_mountains` → `fill_mountain_data` adds each
placed mountain's `tcoord_verts` z to the vertex the mesh vertex stands on,
once per mountain:
- `MountainRange::init` builds those vertices from the `TEMPLATE_TEX`
  pixel's **first byte**, taking every 4th pixel whose alpha is set;
- each adds `byte · (height · 3.0f) / 255.0f` in singles, where `height` is
  the `<MOUNTAIN>` attribute (450, 250 or 100);
- the cells walked are `mount_wx/wy`, which is `Template.cells`;
- run1000's nine mountains agree on all 98 vertices they raise.
