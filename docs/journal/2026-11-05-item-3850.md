**Spline points** (`make_riverlist@00693820`, decompile lines 360–560). Each of the three stretches
`sim::map_rivers::make_riverlist` marks is its own River, started in that order:
- stretch 1 is `0..a` when `a != 0`;
- stretch 2 is `max(a,1)−1..b` when `b != a`;
- stretch 3 is `max(b,1)−1..len` when `c != b`.

Each marked cell is also `add_spline_point(cell)`. On a **border end** (sim's `edge`), the end cell is
added again to the last-started River, then one off-map point: `(−1,y)` if x==0, else `(x,−1)` if
y==0, else `(xs,y)` if x==xs−1, else `(x,ys)` if y==ys−1. **Plan**: add
`pub rivers: Vec<Vec<(i32,i32)>>` to `MapGrid` (one struct literal, in `MapGrid::new`) and push the
points in `make_riverlist`.

`add_spline_point@00885a40`: the point is `(from_i32(768x+384), from_i32(768y+384), 0)`.
`creation_distance += sqrt(dy²+dx²)/768`, where dx and dy are the previous point minus the new one,
the sum is `dy²+dx²` in that order, and the sqrt goes through double (`0x41e6f0`, so ≡ `sqrtss`).

**`River::calculate`, inlined at 0x8858e0**: for each River with `calculated == 0`, in order:
1. `ensure_ocean_end`;
2. `depth = (u16) to_i32(creation_distance · 1.7)`, `degree = 3`, then `Spline::calc_spline`;
3. `RiverOut::create_sections(0, 0)`;
4. `Terrain::spot_update_land_batch(spot_update_wcoords, land 0, riverbase)`.

**`RiverOut::ensure_ocean_end@00885400`** needs n ≥ 3:
- Take dir = L − P (last minus second-to-last). len² = (dy²+dx²)+dz². Normalize when len² ≠ 0 and
  ≠ 1 (`inv = 1/sqrtss`, then multiply).
- If dir.x == 0 and dir.y == 0, take dir = L − third-from-last, *unnormalized*. If it is still zero,
  return.
- End cell: `div3(to_i32(L.x)>>8)`, likewise for y.
- Over MOVE_49 (`crate::world::MOVE_49`, the same tables 0xadcaf0/0xadc400), each cell that is
  off-map or has land 2 is a candidate:
  - v = (768cx+384 − L.x, 768cy+384 − L.y), stored for every candidate;
  - if `(v.y·dir.y + v.x·dir.x) + dir.z·0 ≥ 0`, take dist = sqrt(vy²+vx²+0) through double;
  - if dist < best (best starts at 0x49742400 = 1e6), it becomes best.
- If found: `add_spline_point(best)`. Then w = (v_last − dir), **v of the last candidate scanned, not
  of the best**. Normalize w as before and step one cell: `div3(to_i32(768bx+384 + wx·768)>>8)`, same
  for y. If that cell is on the map with land 2, `add_spline_point` it.

**`Spline::calc_spline@00912f00`** (type 3 = bspline, flags 0x20 from `River::init`; Recycler pop
→ `clear`):
- if n ≤ degree, degree = n−1 (restored after);
- `max_control_depth_ratio` is 0, so no cap;
- if depth < degree, depth = degree;
- `generate_bspline`, then `build_normals` if any verts were made.

`clamp_knots@00910be0` (no weights): n+degree+1 knots — degree+1 zeros, then 1, 2, … up to n−degree,
then the last value repeated through index n+degree.

**`generate_bspline@00911820`** (listing read):
- delta = (k[last]−k[0]) / from_i32(depth), set to 1.0 if it is 0;
- t = k[0]+delta; push cv[0]; i = 0;
- while k[last] > t:
  - span search from the current i: advance while i+1 < count and (t > k[i+1] or !(k[i] < k[i+1]));
  - if i > last, break;
  - sum over m from max(i−degree, 0) to i of cv[m]·B(t,m,degree), accumulated from +0 per component;
  - push the sum; t = t+delta;
- after the loop: if `(double)(k[last] − (t−delta)) > 0.001`, push cv[n−1];
- if no verts were made, copy the control verts.

**`calc_bspline_basis@009116e0`** (listing):
- if i+d ≥ count, the result is 1.0;
- if d == 0, the result is 1.0 when k[i] ≤ t < k[i+1], else 0;
- otherwise: a = 0. With n1 = t−k[i] and d1 = k[i+d]−k[i]: if n1 > 0 and d1 > 0, then
  a = B(t,i,d−1)·(n1/d1).
- With n2 = k[i+d+1]−t and d2 = k[i+d+1]−k[i+1]: if n2 > 0 and d2 > 0, then
  a = a + B(t,i+1,d−1)·(n2/d2).

**`build_normals@00911f60`** (listing; flag 0x20 sets up = (0,0,1)):
- For each segment i = 1..n−1: d = C−P. total += sqrt(dy²+dx²+dz²) through double.
- cross n = (uz·dy − uy·dz, ux·dz − uz·dx, uy·dx − ux·dy). len² = (ny²+nx²)+nz². Normalize when
  ≠ 0, 1.
- s = prev_n + n, with prev_n starting at 0. Normalize s the same way and push it; then prev_n = n.
- After the loop, push the last n itself (flags 4 and 0x10 are clear). That gives n normals.

**`next_at_dist@00912b70`** (listing; step in xmm1, ratio on the stack):
- If curr < 0 or scan < 0, return 0.
- scan += 1; next_search += step (this is the target); minstep = step·ratio; seg = −1.
- While scan < n and target > curr: seg = sqrt(dy²+dx²+dz²) of segment scan; scan += 1;
  curr = curr + seg.
- Then scan −= 1.
- If curr > target and scan < n and total − target ≥ minstep:
  - if seg < 0, compute seg for segment scan; f = seg == 0 ? 0 : (curr−target)/seg;
  - pos = v[s] + (v[s−1]−v[s])·f;
  - nrm = n[s] + (n[s−1]−n[s])·f, then `Vector::norm@00420870` (normalize when len² ≠ 0, 1);
  - return 1.
- Else pos = v[s], nrm = n[s]. If s+1 ≥ n or curr ≥ total: curr = total, scan = −1, return 0.
  Otherwise return 1.

**`create_sections@00884e00`** (listing):
- Return if fewer than 2 verts.
- Set curr, next and scan to 0 when there are verts and total ≠ 0, else to −1.
- The first `next_at_dist` runs with **step 0** (xmm1 was zeroed at 0x884e6c), ratio 0.33
  (0x3ea8f5c3), and gives pos = v[0], nrm = n[0].
- delta = false. Then loop:
  1. cur_frac_x += 1; at 50 it wraps to 0 and cur_frac_y += 1, which also wraps at 50. Both start at
     0 per River.
  2. last = last_width.
  3. The width w:
     - with delta: w = minss(2·max_width, last·1.5);
     - without: w = (byte·0.005 + 0.5)·max_width, where byte = `width_fractal.get_height(fx, fy)`
       and the fractal is `Fractal::init(50, 50, 2, flags 2, seed 0)` (`River::one_time_init`, the
       listing at 0x883e07; every River builds the same one).
  4. prev = (pos, nrm); last_width = w; (pos, nrm, ret) = next_at_dist(768/1.7, 0.33).
  5. Without delta: m = (pos+prev)·0.5, tile = `div3(to_i32(m)>>6)`. If that tile is in range and
     wet (mask & 0x30 == 0x20): delta = true, w = w·1.5, last_width = w.
  6. `RiverSection::init(center1=prev.pos, orthog1=prev.nrm, center2=pos, orthog2=nrm, len1=last,
     len2=w)`.
  7. Repeat while ret ≠ 0.
- Then (param_1 == 0): copy `tcoords_to_smooth` to L; while the list is non-empty,
  `ensure_45_deg_slope(list)`; then `smooth_tcoord(i % 4xs, i / 4xs)` over L, twice
  (`sim::map_heights::smooth_tcoord`).

**`RiverSection::init@0088c360` → `create_trough_and_water@00889f20`** (listing). Three edges, and
the flags are colour only:
- edge(center1, orthog1, len1);
- edge((c2+c1)·0.5, (o2+o1)·0.5 unnormalized, (len1+len2)·0.5);

Consecutive sections share their ends, so a shared edge terraforms twice.

**`create_trough_edge@00889660`** (listing; width in xmm3; param_6 = param_7 = 0):
- sx = (((w·o.x)·2)·768)·0.125, likewise sy; x = c.x − sx·4, y = c.y − sy·4.
- For each of the 9 vertices i:
  - depth = (D − tbl[i]·D) + ((D·0.25)·(−1.0)) with D = −60 and
    tbl = [1, .75, .26, 0, 0, 0, .26, .75, 1] (0xb69870, 0xb69ac0).
  - tile = (div3(to_i32(x)>>6), div3(to_i32(y)>>6)).
  - **Tile in [0,4xs) × [0,4ys)**:
    1. If the tile is wet and 0 > depth and |i−4| ≤ 1: depth = ((depth−30)+depth)·0.5.
    2. `terraform_from_river_vert(x, y, depth)`.
    3. Over the 3×3 tiles round it (MOVE_8 plus the centre; order immaterial): if any of the
       neighbour tile's four corner heights is < 0 strictly, and its cell has none of 0x10, 0x28,
       0x800, and is HALFLAND or has land ∉ {1,2}, and has no 0x40, `blocked` == 0 and `CoordInfo`

div3 is floor division (`init_coord_lookup_array@00681db0`: (i−2)/3 for i < 0), and `to_i32`

**`terraform_from_river_vert@0088b360`**:
