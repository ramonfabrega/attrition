- **4239b. The renderer drew no new surf for 14 frames before run1564's packet.** `last_time` is frame 3280 at
  game frame 3294. `Surf::draw` rebuilds only when the section render is on (`scalability.section_render`) and the
  frame or camera moved, so either the section render was off or the draw did not run on those frames. It names no
  score: the photograph is the lists' frame.

For the Loop: one finding for the pass. A packet's renderer statics can be older than its frame: `Surf::last_time`
lagged `gamec->frame` by 14. Read the rebuild's own clock before diffing a renderer list against state stepped to
the packet's frame. The 14 came out of a scan in one run.
