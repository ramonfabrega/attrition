## The mechanism

non-mandatory attack by a captain, whose target **is not a unit**, runs
`find_new_target` on every frame, with no roll. The search is a human's,
twelve tiles. The Airbase is 10.6 tiles from the Fighter's seat, where
the search re-found it on the birth tick. It is 12.2 tiles from the
attack point, where the search finds nothing. This crate carried the arm
for unit targets only, as §8.2's one-in-five.

false)`, which was already there for the collision ladder.
