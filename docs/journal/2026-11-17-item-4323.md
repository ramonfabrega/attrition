## What the reading settled

- **The loop is three passes, but one set.** The passes run `local_c` over 0, 1 and 2. Each pass adds the types
  with one value of the arm's flags: 0 in the first pass, a flag set without bit 2 in the second, bit 2 in the third.
  So every type that reaches the add is added exactly once. The passes decide the buttons' order and `disable`, not
  the set.
- **The arms, for a technology `t`:**
  - `t` held and queued here: offered only if it is a government (`is_gov_type`, `0x26e < t < 0x275`).
  - Else, `researching` drops it.
  - Else, if not queued here, the building's `upgrade` (`+0x44`, through its graft) must queue it, and at
    `type_avail` 0 `show[0]` or `show[1]` must be held.
  - Then, at `avail` under 2, the type is offered only if `show[0]` or `show[1]` is held, or
    `show_later_tech(t, 5)` answers yes. A government also needs `type_eligible`.
- **`show[2]` is `SHOW0` and `SHOW1`.** `TechType::init@0066c7b0` writes them through `tech_key` into `+0x50`
  and `+0x54`, and `types.txt` names `TypeData::show[2]` there. `disable` is `TYPE_NOT_AVAIL` (−2), the same
  value as `TYPE_ANY_BUILDING`, for which `has_tech` answers 0. So the sim's `has_tech_p` is right as written.
- **`BuildData::show_later_tech@0062d920`** answers no in any of these cases:
  - the game's `ending_technology` is below the tech's `AGE` (`+0x1c8`, the column `TechType::init` reads);
  - a prerequisite is disabled;
  - a prerequisite is unheld and either queued here or made at the Library (`where` `0x1b3`);
  - a prerequisite is unheld and the recursion runs past depth 5.
- **The Library's tail.** After the loop, a building that `is(LIBRARY)` is given every type in `0x220..0x243` it
  does not already offer, greyed. These are the seven ages and the 28 epochs, the Library's 35. The finals
  (579 to 582) are past the tail, and the loop drops them.
- **4321a is not the loop's.** `researching`'s same-line arm asks `is_unit_type` of both the queued type and the
  asked type, so it never answers for a technology.
