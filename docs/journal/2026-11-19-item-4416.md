## The rule the port needs

Read from the decompile and settled at the listing; **one reading, no diff yet** (the row is that diff):

- **The list**: the tribe file's `<CITIES>` `<CITY>` texts, `L` of them (`tribes/nubians.xml` begins `Napata`,
  `Axum`, `Meroe`). `XML::init` on `Tribe::file` (`+0x4`) under `int_str_array +0xb90`, then `get_elements` of
  `int_str_array +0x2864`; a missing root or an empty list names the city `Tribe::name` (`+0x18`) and steps no
  counter (`docs/LEADERS.md` §1.2, gate (c)).
- **The step** is `leaders::words::name_step`, already ported (`n` the winner's new count, `prev` the owner's count
  before it). Then, in order:
  1. `n >= L`: the name is `Tribe::name + " " + (n + 1)` (the separator is `loc_str_array_orig +0x15e0`, read off
     ch94p's packet: one UTF-16 space).
  2. `n <= 1 or prev == 0` (`7361c4`–`7361cf`): `idx = 1 +` the slots `k < own` whose `tribe` is the owner's (no
     liveness test; unused slots hold tribe −1 on every packet, so they never count); the second store.
  3. otherwise (`7361d5`–`73627d`): `m` = the slots of `0..8` of the owner's tribe, `M = L − m + 1`,
     `x = (tribe + world.seed) mod M + 1` (signed `idivl`; `tribe` is `Leader +0xc`, the index, not a name), then
     a Galois step `if x & 1 { x ^= 0x170 }; x >>= 1` (`sarl`) repeated, **rejecting `x >= M`, and stopping on the
     `(n − 1)`th accepted value**; `idx = x + m`.
  4. `idx > L` (`7362dc`, signed `jle`): `Tribe::name + " " + (idx + 1)`; else `<CITY>[idx − 1]`.
- **Exempt from the list** (`set_name` and no step): the Forbidden City (`is(0x213)`) takes its type's name
  (`type +0x74`); Conquer the World for a non-barbarian tribe takes `ConquestGame::get_city_name`, and at frame 0
  nothing.
- **The inputs on disk**: `world->seed` is 7236 on every packet, which is `Sim::game_seed` (`lib.rs`, item 4347);
  slot tribes and counts read as the leaders line holds them (e.g. ch94p `[4, 11, −1 …]`, `city_name [1, 1, 0 …]`).
  No packet name carries a digit, and none is empty, so neither suffix arm is reached by the row.
- **A city is named once.** `generate_name` runs from `City::init` alone, under `activate`'s first argument 0 (the
  start city and a city built). A capture runs `init` with 1 and does not rename; what name a captured city carries
  (the old record's, or none) is not read.
