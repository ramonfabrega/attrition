## 3. The clamp, read

- **The card.** `RenderState` (`rise.pdb`, 0x168 bytes) holds `address_u` at `+0xdc` and `address_v` at `+0xe4`,
  one per stage. `TexAddress` is `TEXADD_WRAP` 0, `TEXADD_MIRROR` 1, `TEXADD_CLAMP` 2 (the type record's field
  list `0x59CC`). Draw 36 reads **(0, 0) on stage 0 and (2, 2) on stage 1**. Draw 162's stage 1, `fow_fade.tga`, is
  clamped too; draw 121's mask wraps, and draw 122 clamps both stages.
- **The texcoords.** The second layer's are `−xy / 6144 + (8.750, 8.680)`. Over the packet's 624 floor vertices
  they start at **2.180**; over the view's `OCEAN` pixels at **2.432**. Both axes clamp to 1.
- **The texel.** `ImageIO::decode_tga@00546e10` writes a bottom-origin file's first row to the surface's last
  (`YReversed == 0`: the start at `(Height − 1)` rows, the pitch negated). So the surface is top-down as displayed,
  and `(1, 1)` is its last row's last texel. On `tilesets/dirty/ocean_floor_5.tga` that is (182, 246, 255); with the
  tint, (200, 255, 255). The first layer's mean red is 71 (89 tinted), so the product loses far less red than the
  mirrored layer's 72 gave.
- **The stages saturate once.** `do_texture_operation` (`shaders/shader_texture_data.h`) clamps no stage; the
  product is saturated in `ps_global.hlsl`. `floor_stage` had clamped the doubled first layer before the second.
- **d3dgl uses the second texcoord.** The dll carries `TEX1_UV1` as a define, the name `ps_global.hlsl` tests.
