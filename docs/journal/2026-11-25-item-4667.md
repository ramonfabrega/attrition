unit, the type carries `SELF_DESTRUCT`, and `valid_target(unit, collider)` answers, `Sim::ram` runs and the resolver

square, `ground_z + 100`, the angle toward the collider), then `die_with(3)`. There is no swing, turn or reload.
Every collider this crate records is a unit (`record_hit`, `name_pusher`), so the original's `(o, who)` resolves
through `collider_of`.
