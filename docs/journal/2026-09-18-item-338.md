## 2026-09-18 — item 338: Great Lakes 8272 was the game's first scholar, and East Indies' word was the same event (Opus 5)

The item was booked as a **widening and nothing else** — no dumped record
covers 8272, the map's detail captures stop at run19's 8201, and the brief
said plainly that a capture brief might be the whole product. One candidate
was named (parked 333) and warned against. It is not the answer and is still
parked. No capture was needed.

**The disk first, and it held.** Every `gamelog-*.txt` on this machine, by
`BEGIN FRAME` range: on Great Lakes nothing between run19's 8201 and run80's
23960 except run53's own 24000/24001. So at 8272 the only record either side
has is the trace's draw sites.

**The widening took one run.** `RON_DEBUG_SITES=8220-8320` on run53:

```

  frame 8272: ours  38 theirs  38   — agree on the COUNT, part at index 33
  frame 8273: ours   3 theirs   3   — agree
```

Thirty-three entries identical, and index 32 is `Guy::init_real+0x52` on
**both** — a unit is born, on the right frame. The original's 33rd is the
bare address `5dac7a`, which is `Guy::set_anim+0x97a`: the same site as ours,
under a caller [`SITES`] does not carry. `report.py … draws 8272` prints the
chain and the hypothesis never had to be made:

```
  32: Guy::init_real+0x52  < Unit::init+0xb97    < Objects::init_unit+0xbd
  33: Guy::set_anim+0x97a  < Unit::set_anim+0x56 < Unit::go_inside+0x280

A **fourteenth** caller of that address, and the last one left. Ours spent a
fourth `Guy::inc_time` wrap there instead, and the attributed fold names the
unit without a guess: **`1/44`**, which appears exactly once in the whole
hundred-frame window.

**`report.py … when` is what made it a mechanism rather than a frame.**
`Guy::set_anim<Unit::set_anim<Unit::go_inside` fires on fourteen frames of
run53's 24,000 — 8272 first — and **every earlier birth spends none**: 6612,
6993, 7212, 7439 and 7674 are three units apiece and 6762, 7765 one each. So
the arm is gated, and whatever the gate is, 8272 is the first time in the
game it holds.

**Only then the decompile, and it took one grep.** `Unit::go_inside@0061a2e0`'s
last block but one:

```

`UnitTypeData +0x4 in {0x34, 0x35}` is not read off the surrounding code —
it is verbatim `ObjectData::is_scholar@0046d330`, whose whole body is that
comparison, sitting between `is_peasant@0046d310` and `is_worker@0046fa10`.
**8272 is the first Scholar in the game.**

The `force` argument is the point. It skips `Guy::set_anim`'s "already
playing" early returns, so the idle roll is unconditional — one draw — *and*
it gives the new guy a real `end_time`. Without it the guy keeps
`Guy::init_real`'s zero and wraps in `Objects::inc_time` the same frame. One
draw replaces one draw, in a different phase: which is exactly why the
**count** never parted at 8272 and only the order did.

**Then the word moved thirteen frames and the second arm showed itself.**
8272 → 8285, and 8285's extra draw was `1/44` again, seating itself a
**second** time. `Build::train@0062f9b0`'s exit block splits on the trainer:
when the building answers `ObjectData::is(0x1a4)` — the University, the test
`num_scholars`, `calc_gather`, `num_gatherers` and `could_queue` all use — it
re-reads the *trained type's* `is_scholar` and compares `BuildData::gather_max`
(`+0x80`, a `char`, settled by the type record) against `num_inside(1)` after
the unit is in. At or under the limit it calls `check_gatherers` and the
scholar never reaches the exit ring. This crate ejected every trained unit,
so `1/44` was born, thrown out, and walked back in over thirteen frames.

With both arms: **Great Lakes 8272 → 8374** (word and sequence now part on
the same frame), and 8272–8340 agree entry for entry.

### What this did not establish

- **Which university a scholar walks to** — the four above. A `do_gather`
  target choice, and run80's block refuses any answer that does not put seven
  in each.
- **`Build::train`'s outer gate is read, not diffed.**
  `(BuildTypeData +0x1e4 & 0x200) == 0` — `obj_masks`, by the type record —
  skips the whole exit block when set, and this crate does not model it. Nor
  is the `gather_inside` arm on the non-university side modelled. The
  falsifier is named in `docs/CITIES.md` §6.5.2: a `BUILDS`+`UNITS=3` window
  over a **full** university, where a fifteenth scholar must appear on the
  exit ring within a block.
- **The two widening arms of `go_inside`'s own gate** are untested for the
  same reason 336's were: nothing on disk has a non-scholar reach them.
- **`leaders.list[who] |= 0x2000000`** is a repaint flag set by a dozen
  callers and read by nothing this simulation models.
