A script cut each file from the raw string's bytes between `r#"` and `"#`, so each is that string
character for character, the leading newline included. **The tree's pass was a `format!` literal**:
its `{{`/`}}` are now single braces, and each `{NAME:?}` is a `{NAME}` hole that `tree_shader()` fills
with `format!("{NAME:?}")`, the same `Debug` formatting as before (`current`, `FAKE_LIGHT_POWER`,
`HDR_SCALE`, `EXPOSURE`, `white`). `the_tree_template_s_holes_are_filled` requires each hole exactly once
in the template, none left in the result, and no other `{` followed by a letter.

**`client::trees` held no WGSL.** The trees' pass lived in `gpu.rs` as `tree_shader()`, which is what
the queue's `client::trees` names. `trees.rs` holds the colour model and its rows, and it is unchanged.
