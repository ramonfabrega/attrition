hits / uber` only when vslot `+0xe8` (`is_captain`) answers **and** `UnitData::curr_uber_size(this, 1) == 1`. That
is the last figure standing. `docs/COMBAT.md` §7.2 step 8 already read the rule correctly. Ours' predicate read
the stored `Unit::squad_size`, which nothing outside the tests writes past 1.
