## The cache key, read first

`crates/sim/src/sweep/support.rs`'s `cache_key` hashes `emu-cache v1`, the executable's sha, the script's sha,
each shared module of `tools/emu` by name and sha, and the arguments (for an `obj` sweep, its snake and its row's
literal from `sweep_obj.tsv`). **No path enters it**: not the sweep's source path, not `file!()`, not
`module_path!()`. `emu_obj` and `emu_rows_args` find `tools/emu` from `CARGO_MANIFEST_DIR`, which a move
inside the crate does not change. So moving a sweep's `.rs` file, or rewriting its Rust, can re-key nothing.

after every sweep target and the library's `sweep::` had run green, it still held exactly those 2,344
(`comm` of the listings: 0 new).

## (4) The fold: `sweep::support::obj_rows`

One function in `support.rs`, `obj_rows(rows, &Obj { name, full, cells, calls, eax, min_rows }, port)`, holds
the row-parsing and asserts `sweep_gen.py` generated into every `obj with windows` test. The port is a closure
`|a, m, c, p, log| -> i64` over the same slices the generated `let (a, m, c, p) = (&a[..], &mut m[..], …)`
handed it. The test keeps its `///` line, its `super::emu_obj("<snake>")` call and its full name, so the
census's regexes read each folded chunk as before (re-measured: byte-identical).

**The rule that made it safe** (a scratch script, not committed): a file was folded only when
- its skeleton, rendered back from the five parameters read out of it (`cells`, whether calls are recorded,
  whether `eax` is asserted, the row floor, the two names), equalled the file's own. String literals had to
  match byte for byte; whitespace outside them is `cargo fmt`'s.
- the p-window offset was `1 + cells`, which `obj_rows` computes.

That gave 820 of 914. The other 94 have a hand-edited skeleton (58 differ, 16 lack the binding line, 12 carry
items after the test, 8 lack a parameter) and are untouched. Then the compiler checked: a port that read a
skeleton local cannot compile inside a closure. 33 did (they read `line`, the row text, or `want_eax`, `want_log` or `after`), and those were restored
whole from the previous commit. **787 folded.** A port's
`&mut log` became `&mut *log`, the same reborrow, now that `log` is already `&mut Vec<String>`.

The check that the asserts are the same: every sweep was run on the warm cache with the install
(`RON_INSTALL`): `sweep_a_f` 293, `sweep_g_o` 388, `sweep_p_t` 254, `sweep_u_z` 414 passed, and the library's
`sweep::` 162 passed. No cache entry was added. Under `--nocapture`, folded tests print their row counts
(`Build::find_target@00622c80: 220 rows agree`), so the rows were really compared and not skipped.
