## What the closing blocks are (established before building)

The item's title named a mechanism; the evidence kept it and corrected its unread half.

- **Who quits, and when.** The quit's one draw is the resign's sound, `SoundGlobal::play+0x2a <
  Player::resign+0x18a < Player::quit+0x20`, on the sound's own generator. run609's trace has it as
  frame 5638's draw 0, before any `game_random` draw; run667's as frame 17379's draw 0. So the human
  (who 0, `leader_flags & 4`) quits **at the head** of the frame that writes the closing block, and
  the frame's body runs after it: run609's conquest (`Cities::capture_city`, `Leader::lost_capital`)
  comes on 5638 after the resign, which is why theirs reads `defeat_type` 6 (the quit's, write-once)
  with `defeated_by` 1 and `defeat_stamp` 5638 (the conquest's captor stamp past the guard).
- **The quit is not always at the head.** run600 (the same French East Indies game as run667) has
  `Player::lose < Leader::defeat < Leader::victory` as frame 17379's draw 7 — the territory win's
  cascade — and the resign as draw 30, after the frame's last `game_random` draw. run1200's resign is
  frame 5639's draw 48, after the conquest and the frame's body. Read: when the game ends,
  `Game::do_frame` ends in `Game::process_end_game`, whose modal `EndGameWin::exec` runs after
  `frame += 1`; the capture's quit is made there, so its re-stamp reads the closing label (run600's
  `defeat_stamp` 17380, popwin 14293 + 3087 — 4185c's one frame).
- **The semaphore that keeps the territory arm from winning after: there is none.** The territory
  arm's gate is `VICTORY`, `num_nations > 1` and balance mode. The quit's `Leader::defeat` ends in
  `Game::check_victory`: no live human, one seated, so the latch is taken and the one live computer
  gets `victory(1, 0, 0)`. That won flag is what the territory arm's `victory(2)` returns on.
  `Leader::victory` also cleans every one of the winner's buildings' queues with no refund (the walk
  from object 2000, vslot `+0x20`: `Build` 1, `Wall` 0; `Build::clean_queue(0)`), which the dumps had
  been showing for months as "the closing frame's emptied queue" on who=1's `*_queued` and
  `queue:queued` rows. `Player::win` draws only for the console player, so the trace cannot show the
  computer's conquest victory; run667's 17380 backs it by elimination and by the cleaned queues.
