## The reading

- `Group::action_recall@006fa7e0`'s building arm: `Build::clear_gather` on every
  member that is active (`+0xc`, `SubObjectData::is_active`, `flags & 1`) and a
  building (`+0x20`, `Buffer::is_pending_load`, which returns 1). That call
  already sends every homed plane home. Then it walks every unit of `who`: a
  fixed-wing plane on the map whose air order's home is a member is closed and
  re-given `add_strafe_order(−1, −1, home, 0, QUEUE_NEW, 0)`, carrying the
  heights of the order it replaces. One inside a member gets `clear_orders` and
  leaves `launching`. On an Airbase, the recall is therefore its Clear's hangar
  half.
- `Group::action_scramble@007111c0`: down each member's `inside_down` chain,
  every domain-2 passenger that is not busy, not a missile and full
  (`mana_burn` 0) goes up: `add_air_patrol_order(host.x, host.y, host, 1)`.
  The listing (`7114dc`..`7114fa`) pushes the host's `y` as the `QueuePos`,
  which the fixed-wing arm never reads. A helicopter instead gets a built
  `MOVE_TO` (reading only).
