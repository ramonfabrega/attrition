**Port consumers**: all ten carry the census's `port` mark. I took the `--unbacked` list's `port` rows from 512
bytes (`WallData::covers_tile`) to 863 (`UnitData::is_moving`), skipping those with a heavier world or a hooked
callee whose out-pointers carry the answer (`WallData::covers_tile`'s `tile_corner`), `BorderNodes::find` (its
`port` mark is the unrelated `supply.rs` `find`), `is_military_trainer`/`is_training_building` (slot against
`basic_type` plus the `buildtypes` table, 2021's shape with a table), `CityData::num_city_buildings`,
`UnitData::can_garrison`, `is_flying_high`, `is_modern_infantry` and `air_turn_speed` (a float from `+0xf4`). Two
tests call the port itself (`CityLevel::pop_cap`, `Unit::discard_current_path_segment`); three hold port
constants; the rest inline the original's arithmetic beside the port's name, since each port is a `Sim` method
on the port's own state.

**The generator**: none of the ten by `sweep_gen.py`; all by hand on `hooks.py`. Four read a per-player object
table (`TABLE + who·0x1c` → an array of record pointers), which `obj --at` cannot lay (parked 2039). Two compare a
vtable slot with an address — the 2021 comparison — but neither arm is 2021's field test, so a `vcall --base`
with a field arm would not have taken them, and I did not build it (parked 2040, with the `mix`-mode form that
would). No two were the global-cell WCoord shape (`cell --ptrargs`, 1994) or a torn-frame forwarder (`vcall
--jmp`, 2013).

**What the listing said**: `Region::is_coast` reads its set inline at `+0x64` (`testb %al, 0x64(%edx,%esi)`: the
decompile's `coast.ptr[…]` is bytes inside the record, not a pointer dereferenced); `UnitData::needs_transport` reads the first
tile as a `u16` and the second as a byte, both masked `0x30`, so they agree. `CityData::pop_cap`'s `who` is the
*signed* byte at `+0x5e`. `kill_current_path`'s `count < 1 → 1` clamp is unreachable: the loop runs only while
the count is positive.

**Assumptions, stated**: every per-player table row holds `who` to 0..9 and the index within the laid array; a
sea region is never handed a negative argument (it would index before the list); `kill_current_path`'s callee
takes no stack argument (`ret`, held by the `esp` check).
