How it was done. 4011's method, with a scratch script that is not committed:

- **The eponymous file becomes its directory's `mod.rs`** (`orders`, `combat`, `air`, `economy`, `tech`, `ai`, `gaia`),
  with its siblings declared at its end. Its module path, its tests' names and its line numbers all hold. The other
  directories (`groups`, `spells`, `cities`, `leaders`) got a two-line `mod.rs`.
- **The nested directories.** `army.rs` became `ai/army/mod.rs` and `transport.rs` became `ai/transport/mod.rs`. Each is
  declared by `ai/mod.rs`, and its old test directory's files (`army/tests.rs`, `transport/tests.rs`) joined it. The
  script's first try put `army/` one level too deep, at `ai/army/army/`. The compiler refused it (`file not found for
  module tests`), and I mended it by hand before the commit. No citation pointed into `army/`.
- **The shim**: `lib.rs`'s `mod f;` lines became `pub use self::<dir>::f;`, one line for one line. **`lib.rs` stays at
  8,252 lines**, so no `lib.rs:N` citation moved. A private root module nothing names through the root
  (`mod build_family;`) would leave an unused `use`, so its line is now a comment saying where it went.
  `pub(crate) mod construct;` became `pub(crate) use self::cities::construct;`.
- **What the source said, before the first move.** The 121 files and their test directories contain no `module_path!`,
  `file!()`, `line!()`, `type_name`, `include_str!`, `#[path]`, `pub(super)`, `pub(in …)` or `macro_rules!`. Their
  `env!("CARGO_MANIFEST_DIR")` paths are relative to the manifest, which did not move. The only production `super::`
  is in `orders.rs`'s own inner modules, and those are still `orders`. So no output a test matches changed.
- **Citations.** `paths.py move` rewrote 1,589 citations across the twelve moves it logged; `orders/`'s count went
  unlogged. Two rewrites were undone, because a move rewrites the text files under `tools/` too. One was
  `tools/paths.py`'s own docstring example (`{air,nuke}.rs`), and the other was the fixture paths of
  `tools/explore/test_release_gate.py` (a sim edit to `fight.rs`). Both name no real file's place, so they stay as
  written. The script restores those two and `tools/test_paths.py`/`tools/test_shape.py` after every move. One
  citation did not follow, for the same reason 4011 met with `supply.rs`: the bold citation of `cost.rs`'s old path
  in `docs/audit/2026-08-20-costs.md`, mended by hand. `--check` now lists only the 12 pinned citations.
