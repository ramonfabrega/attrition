## The cause

`no_danger` (`PathFinderData +0x7c`). `astar_path`'s prologue sets it from
four terms, and the listing has them in order at `00683866`–`006838a3`:
- `get_action`'s `get_type() == 0xa` (an attack action);
- `who >= 8` (unsigned);
- `order_type == 2` (`ATTACK_TO`);
- `order_type == 0x15` (`GROUP_ATTACK_TO`).

§2's own table row already said so. This crate's `Sim::no_danger_mode`
carried the first term only. The column walks under an `ATTACKTOORDER`,
so ours priced who=1's negative home danger. That made the straight road
north up to 56 cheaper a step, and `1/58` took it.
