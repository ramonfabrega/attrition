2. **The blow's inputs** (probe): SAM building type 111, `attack` 290, `obj_masks` 0x82000000, `ammo_per_att` 1.
   Capital building type 2, `armor` 7, active, roles `IS_CITY`. `pct[SAM][capital]` is 100. The table is built at
   load, not shipped in the PE, and `rondata --types` already diffs it whole against run3's `COMBATTABLE` dump. So
   the brief's first act, the PE cell, is the table ours already holds. `BuildData::attack@0062e610` and
   `ObjectData::attack@006469f0` add nothing for the SAM.
3. **`Object::do_damage@0064a480`'s scaling** for a building attacker is `dmg × count / type+0x208` (`:240`–`:250`),
   which is 22. So 44 has to come from `get_damage@00644130` itself.
4. **`get_damage`'s last step** (`:477`–`:494`): T is Build-proper, active (`flags & 4`), a city building
   (`BuildData +0x8 & 0x20`) with a city (`+0x72 >= 0`) whose `race` (`CityData +0x5f`, confirmed in `types.txt`) is
   the attacker's `who`. Then `dmg = dmg × recapture_city_modifier >> 8` (512, ×2). **Nothing asks who owns the
   building**, so who=2's SAM hitting who=2's capital (race 2) is doubled. Ours had the step (`damage.rs` step 28)
   but **`Side::recapturable_city` had no writer**: declared in `combat.rs`, defaulted false everywhere. A dead
