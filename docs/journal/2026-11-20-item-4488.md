## The predicate

Ours' `Sim::close_unit` returned before the death-animation draw for any
unit with `role::IS_MERCHANT`. That role is Merchant, Dutch Merchant and
Fur Trapper, the original's `0x3d`, `0x3e`, `400`. The original's gate is
`local_1c == 0` (`Unit::close@0060ee50:461`). `local_1c` is set to 1 only
at `:194`, at the foot of the arm at `:170`–`:194`. That arm needs the
type **and** `unit_masks & 0x80000` (packed) clear **and**
`UnitData::is_packing@0060aa60` answering 0. Only then does it unblock the
four tiles. So the original exempts only a deployed Merchant. A packed one
dies like any unit: one `Random::get` (theirs' `Unit::close+0xcb6`, 4475),
then `kill_guy` per figure.

The same arm's other half was already right here. `territory/upkeep.rs`'s
merchant close raises the leader's `0x2000000` for any merchant, and it
returns the footprint only when the unit is neither packed nor packing.
Only the death-draw half had dropped the two clauses.

**Built**: `crates/sim/src/combat/fight/delivery.rs`, `close_unit`. The
merchant return now needs `!u.combat.packed && !self.is_packing(i)`.
