`LeaderData::get_caravan_limit@006dca50`, with argument 1, starts `n` at the leader's own `city_num` (`+0x3f8`).
When `has_preq(BASE_BONUSTYPES)` holds, it walks the eight slots. A slot is counted when it is seated (`leader_flags
& 1`, the byte at `list[j] + 0`) and is not this leader. It must be either this leader by `who` (`+0x8`) or a
mutual ally: `list[j].diplos[who] == 2` (`+0x74 + 4·who`) and `list[who].diplos[j] == 2`. Each counted slot adds
its `city_num`. The bound is `n (n − 1) / 2`. The types record names the offsets: `LeaderData` is the head of
`Leader`, 0x6eec bytes, the loop's stride. `BASE_BONUSTYPES` is TI 684. Its `has_preq` takes the generic path, so
it is Trade, `roles.ally_caravan_preq`, which `do_trade` already reads (`Sim::ally_caravan_preq_held`).
