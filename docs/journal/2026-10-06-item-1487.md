## Why 14332..14844 did not stamp

If only the ×100 is built, ours' army 0 takes Napata on 14332. The
original did not: run639's 14777 shows no stamp. The head of
`find_target` holds the answer. A land army is weak when Military is past
2, `type_avail(SUPPLYWAGON)` is non-zero and it has no wagon, and a weak
army skips every enemy city. Army 0 has no wagon. Army 6 carries `1/72`,
a `SUPPLYWAGON` (63). `docs/ARMY.md` §20.4 had this clause on file as a
seam that "no capture reaches".
