The commander's list named seven pieces. §3 assigns four more out of `lib.rs`: diplomacy to `leaders/`, the spell row
and job times to `spells/`, `process_movement` to `movement/`, and attrition and supply to `territory/`. Those went
too, since without them `lib.rs` would have stayed near 2,000 lines. The cloak block went to `combat/`, which §3 does
not name.

**How.** A scratch script, not committed. It splits `lib.rs` into chunks: an item together with the run of `///`,
`//` and `#[…]` lines just above it, through to the next such run. It does this at the root and inside the one
`impl Sim`. It writes the chosen chunks to the new file in their original order: top-level items first, then one
`impl Sim { … }`. Each new file opens with `use crate::*;`. It removes the chunks from `lib.rs`, adds the `pub use`
re-exports beside `pub use world::…`, and appends the `pub mod` line to the parent's `mod.rs`, which rustfmt then sorts.
Every method keeps its path `Sim::x`, so no caller changed.

**Privacy, the one kind of edit.** 55 private `Sim` methods became `pub(crate)` on their signature line, and so did
`Muster::new`. No body changed. The exceptions were private items that only their new file reads: the four
type ids in `spells/job_time.rs` stayed private. The enum `Advanced` is named only by `harness_tests.rs`, so the root
imports it as `#[cfg(test)] use cities::queue::Advanced;`. Every moved `pub` type and constant keeps a root `pub use`
(`Unit`, `UnitType`, `Muster`, `Building`, `Produced`, `Tick`, `Marks`, `HeadSerial`, `Refused`, `Movement`, the bands,
the frame constants, `turning_of`, `init_form`). The four `pub(crate)` free functions keep a root `pub(crate) use`.
So every path `rondata`, the sweeps and the documents name still resolves.

**The tick is verbatim.** I diffed `core/frame.rs`'s `Sim::tick` with `diff -w` against the base's `lib.rs` lines
7058–7475 (418 lines, doc comment included). The diff is **0 lines**. All eleven `self.mark("…")` calls are there in the
same order (the brief said twelve; the base's tick had eleven). `rnd` is the base's text, so is `mark`, and so is
every method that draws. No statement was reordered, so the rng stream is untouched.

**One rename after the fact.** `movement/process.rs` became `movement/step.rs`. `tools/nations_census.py` keys a file by
its bare name (`key()`), and `units/process.rs` already holds `Unit::process`. With two files named `process.rs`, one
would have overwritten the other in the census's pool.
