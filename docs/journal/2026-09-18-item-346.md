### Which is exactly what a *silent restart* looks like

`RON_DEBUG_SITES=8404-8404` attributes our one
`Guy::set_anim+0x97a < Guy::inc_time+0x271` to `1/35`, a category-0 idle
running out. Cutting run97's blocks 8404 and 8405 apart by hand named the
frame's five wraps: `1/4` and `1/41` on `CHAR_WALK`, `1/35` on
`CHAR_DEFAULT`, `1/20`'s build stand, and **`1/44`** — Great Lakes' first
scholar, item 340's own unit — wrapping slot 25 to slot 25.

`1/44` is the extra draw. `Guy::inc_time`'s wrap calls
`set_anim(cur_anim, 0, 1)` when the slot loops and `set_anim(DEFAULT, 0, 1)`
when it does not, and only the second draws, so the reading said: the teach
slot must be non-looping. It is not. It is in `anim_graphics.xml`'s
`<LOOPING>` section, and `AnimMgr::force_load`'s last-key rule is an
independent witness — slot 27 is 103 frames under a 1 and 102 under a 0, and
run97's block 8273 reads `end_time 103`. Two hours went on that
contradiction.

### What settled it was the listing, and one register

`Guy::set_anim@005da300+0x2ef`:

```text
5da602  local_20 = UnitAnimCat[cur_anim]
5da613  cx = guy_flags & 0x80
5da619  cmp cur_anim, 0x19
5da624  cmovge local_20, 0          ; a scholar's slot 25+ IS CHAR_DEFAULT
5da62b  edx = UnitAnimCat[param_1]
5da632  test edi, edi               ; edi is PARAM_2, loaded at 5da329
5da63a  jne ..
5da646  cmovge edx, 0               ; and so is the REQUEST
5da709  test edx, edx               ; the idle arm is entered on edx
```

The decompiler prints `edi` as an `iVar12` it has already used for three
other things, and prints both the request's *category* and the final *slot*
as `param_2`. The prologue settles it in one line: `5da329 movl 0xc(%ebp),
%edi` — `edi` is `param_2`, this crate's `force`, and the wrap passes zero
for it.

So the looping restart of a teach slot **is** taken, and `set_anim` turns it
into a `CHAR_DEFAULT` request on arrival: it draws, it rolls, and §4.11's
offset puts the roll back on a teach slot. `loopings` was never the question.

The second half of the same remap is `local_20`, which gates `set_anim:281`'s
variant bands. With the raw category 25 the roll is discarded and the slot is
`0 + 0x19` every time; with the remap the four `Scholar Teach` files are
reachable. run97 shows both: `1/44`'s slot across the window goes

```
27 → 25 → 25 → 28 → 27 → 25 → 25 → 25 → 27 → 25 → … → 26 → 26
```

— twenty-two wraps, at the cadence of the slot lengths 30/100/103/105. A
`set_anim(same, 0, 1)` restart cannot change a slot at all.

`sim::anim::Sim::scholar_cat` is four lines. `docs/ANIM.md` **§5.1**.
