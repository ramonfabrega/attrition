# Item 4640 — The cost of reading the original's unit and figure fields

GPT-6, direct branch `codex/coverage-scout` from `d57298444`. The
previous whole gate spent 338.23 s in the field-coverage test. The target
was 169 s, with the same fixtures, values, from-zero walks and corruption
checks. The user authorized two read-only Astra assignments for this

generations because both replay walks use the current parser.

## Where the time went

On the parent, eight workers took 332.73 s alone. The 435 generic
windows compared each result with a fresh walk from zero. Across the
870 walks, 124 base captures and 3,822,986 ticks, decoding took 942.67
worker-seconds and the ticks inside the comparison span took 702.7.
The native sample of the ten-test German group put text parsing first.

Run912 let us time the operations separately on all 5,973 frames.
Reading 1,948,544,933 bytes took 0.22–0.23 s. Building the field arena
took 2.21–2.28 s. Turning its blocks into typed frames took 3.59–3.65 s.
Encoding, decoding and comparing the complete records took about 0.54 s
in total. This recording contains units and figures and understates the
cost of other sections elsewhere in the corpus.

| Run912 experiment | Time to produce typed frames | Instructions for all stages |
| --- | ---: | ---: |
| Parent, repeat | 3.59 s | 155.54 billion |
| Copy fields to the arena a chunk at a time | 3.59 s | 151.57 billion |
| Read optional unit and object integers together | 2.69 s | 128.26 billion |
| Also read figure integers together and reuse their four tagged words | 1.98 s | 109.75 billion |

Each bulk copy ends at a 65,536-element arena boundary. Traversing one
record backwards preserves the first occurrence of every requested key,
including an invalid first integer. The recorder registers each named
read. Figure angles still require all four slots, and the tagged words
retain their original first-parsable-value rule. The focused tests cover
duplicates, missing and malformed values, the field read set, and copies
over chunk boundaries.

The wider trials reserved every worker they used and matched the parent's
136,071 result rows and all fixture requests. Twelve saved 85.22 s
against the candidate at eight. Going from twelve to sixteen bought
another 4.79 s and cost 356.16 CPU s. The process high-water mark also
rose from 3.64 GB to 5.18 GB. The gate therefore offers twelve as an
explicit quiet-host option. Eight remains the shared-host default.

`release_gate.py --library-slots 12` gives twelve slots to the isolated
library. The coverage test books all twelve and reserves its full
existing 4,608 MiB ceiling. After it finishes, smaller library tests
can fill the pool. The other binaries still use the selected
`--test-threads` and all children pass through host admission. The
gate policy, per-test CPU width, memory lease and ceiling are all
recorded in the ordinary report. The runner tests exercise both widths.
