## The reading

- `Console::down` writes the press's terrain point to both `drag_x` and `drag_x2`.
- Every `on_mouse_move` rewrites `drag_x2` with the cursor's terrain point.
- On the release, a click (`left_click`) and a drag (`on_left_up`'s `selecting_spot` arm, ahead of the box) both call
  `picked_spot(drag_x2, drag_y2, drag_x, drag_y)`.
- The build arm passes all four to `issue_build`.
- `process_build` logs them and calls `action_build`. In the listing, `action_build` reads `+0x10`/`+0x14` only to
  push them into `validate_build`, which reads neither.

So the press's point changes nothing in the game. The whole chain is in `docs/CLIENT_INPUT.md` §38.2.
