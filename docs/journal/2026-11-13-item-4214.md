printed record, seen red on a shifted frame.

  `SyncLogger::logToMemory<unsigned_long_&>@00463930`. `check_all` hands it each of its sixteen lines already computed,
  so the value is read at entry. A call counts when its return address is in `check_all`, keyed by the `line` argument.

  `check_new_frame_playback` → `Game::do_frame`. So a set the tracer tags `f` follows `do_frame` `f`'s `end_frame`.
  Logger block `f + 1`'s end record is record 3201 at trace frame 90.
