- **Steps 1–6 are the map's own script plus shared code.** Great Sahara, Great Lakes and East
  Indies each needed only their `make_continents` style port (`sim::map_east_indies` and its
  siblings) and their XML. From `place_all` onward, every step was shared code that each new map
  met with no change, or with one predicate (`check_player_forest`, 3840). Budget one item for
  the mask and expect the rest to land on first runs.

  East Indies, which has the gate open round every island, needed none. A map with lakes or
  rivers meeting land will go through §16 and should pass.

  trough. A non-empty one goes through `make_riverlist`, `astar_river` (3845) and §17's troughs,

  HALFLAND-neighbour and 0x40 tests, and `ensure_ocean_end`'s normalisation. A fourth map with
  rivers reaching wet tiles or an island coast is the one that would falsify them.
- **Three refusals no map has met**: `Cliffs::init`'s slope test (no 0x40 cell on any of the three
  maps' start dumps, so `has_plus_slope` has never run), a good or goody in a trough
  (`move_goody`), and a beach cell (`convert_beach_to_sandy` entered on none of East Indies' runs).
  A mountainous map with forced cliffs (a Himalayas-style style file) is the cheapest way to reach
  the first. Choose the fourth map by which of these its XML can enter. Check the 0x40 count and
  the `RIVERLIST` first, from the start dumps on disk.
