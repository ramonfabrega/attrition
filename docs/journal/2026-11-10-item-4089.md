## 2. The rotation's reading (done)

The reading is from the listings `5dc786`–`5dc94c` (`GuyOut::draw`), `Quat<float>::set@00420c70`,
`Point<float>::rotate@00420b10` and `draw_unit@008e7da0`'s unparented path `8e8878`. It is ported as
`render::slope`.
- **The world normal** is `B × A = (20·dz₁, 20·dz₂, −400)`, normalized unless |n|² is 0 or 1. It points down, and
  the guy's function negates it.
- **The ease** moves a quarter of the way at each call. The unset `(0, 0, −1)` takes the target whole. The guy tilts
  only when z < `0x3f7fbe77`.
- **The axis** is `n × ẑ = (n.y, −n.x, 0)`, normalized. It is turned by `Point::rotate` with the facing's quaternion,
  `deg + 180`, wrapped to 0..359 the same way, and then its y is negated.
- **The angle** is `−(int)(acos(n.z)/DEG)`. `Quat::set`'s negative wrap is `359 − |a| mod 360`, so the drawn tilt is
  ⌊θ⌋ + 1°. θ is acos of the eased z, and the eased vector is not unit length.
- **The order**: `Transform::init(misc_rot)`, then `rotate_z((int)angle)`, then the translation to the guy's point.
  So the tilt composes before the facing, and both turn about the model origin. The y mirror applies after.
- **Checked numerically**: the model's up leans the way n leans, within 0.05°, at every facing, by ⌊θ⌋ + 1. A turned
  facing fails the check.
- **The predicate**: `+0x14` is `UnitType::init`'s `Categories::find_key(&unit_cats, …)`, which is the `CAT` column
  (2 Mech, 3 Artillery). On the packet it reads 246 → 2, 110 → 0, 50 → 5 and 354 → 4, which agrees with our loader.
