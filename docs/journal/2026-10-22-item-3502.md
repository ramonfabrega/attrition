## The hook

Parked 3442a and 3495a gave the design. Every modifier the executable reads is its own USER32 `GetKeyState`
import, tested on the high byte (`execute_at_cursor@007c6630.c:328-343`: `(char)(r >> 8) != 0`). 3495a read the
IAT slot off the shipped image as VA 0xac53e8. I re-read it with `llvm-objdump -p`: USER32's first thunk is
0x6c53b4, and `GetKeyState` is its thirteenth name, so its slot is RVA 0x6c53e8.

`tools/trace/hold.h` (new) holds the pure parts:
- `hold_import_slot`, a walk of a mapped PE32's import directory that returns the IAT RVA binding `dll!fn` by name.
- `hold_valid`, the span check.
- `hold_held`, the answer: is this key held on this frame.

`tracer.c` dispatches `@hold <vk> <until-frame>` to `hold_line`. The first line checks that the import walk puts
`GetKeyState` at RVA 0x6c53e8 (refusal 2 if not). It then makes the slot writable (refusal 3), saves what the loader
wrote there and points the slot at `hold_get_key_state`. That hook answers `(short)0x8000` while a span holds
`g_frame` for the key, and calls the saved function otherwise. The slot is never put back, and a capture with no
`@hold` line never touches it. Records: `I_HOLD` (31) for each line, and `I_HOLD_ASKED` (32) for the first held
answer of a frame. The row is in `tools/trace/README.md`.

**Tests**:
- `tools/trace/hold_test.c`, built and run by `tools/explore/test_hold_hook.py` (registered in
  `tools/offline_tests.py`), uses a hand-built PE32 image with two DLLs. It checks that `GetKeyState` is found at its
  slot, that the slot before it is a different name, and that the same name in KERNEL32 does not count. It also
  checks that a prefix, an absent name, an absent DLL, a PE32+ image and a missing MZ all give 0, that the DLL name is
  matched without case, and that a bound import with no OFT still resolves. Then the span checks and the
  inclusive-span answer table.
- A source check pins the dispatch, the RVA, the by-name check and the single install site.
- I made it fail on purpose once: with an exclusive span end, "alt on the last frame" and "shift in its span" fail.
