### Where a slow test's seconds go

A probe (`capture::read` and `IndexedCapture::open`, each timed per call;
uncommitted) over the timings file's top 32 tests, each alone:
`capture::read` is ~0.1 s a test — the twenty-sixth pass's shared text
left nothing there — and **`IndexedCapture::open` is not**: the coverage
pin `every_key_the_dump_prints_is_read_or_pinned` spends 91.7 of its 120 s
building 448 indexes, `the_census_is_the_corpus` 30.1 of 32.2, and the
four Great Lakes widenings — run226, run218, run211, run202, the window
whose four tests sum highest in the timings file (192 s) — ~15 s each,
building the **same fourteen** Great Lakes captures' indexes
(run125…run243; run178's alone 4.7 s).

**The finding that reshaped the item**: the brief and the pass read that
as an index nobody keeps. It is kept — `INDEX_CACHE`, in process, by
path, length and modification time — and each of the four opens its
fourteen captures once, so run alone nothing in process can be shared:
only a file on disk can carry an index from one process to the next.

of the tree**, as briefed.

### (2) The suite: the cache evicted by entries, not bytes

`RON_INDEX_STATS=<file>` (kept: one line per open, `hit` or `build`, as
`RON_READ_STATS` counts reads) over the whole rondata release suite, four
threads, under `memcap.sh 20`:

- **before**: 623 index builds for 329 distinct captures and 593 hits —
  **294 re-builds, 144.8 of 289.6 index CPU-seconds** — while every
  distinct index together is **4.0 MB**, half the cache's 8 MiB. The
  bound that evicted was the other one: **32 entries**.
- **after**, the entry bound removed (bytes alone): 336 builds for 328
  captures (8 re-builds, threads missing together), 891 hits, 150.0 index
  CPU-seconds; **the rondata suite 641.4 s → 611.1 s**, wall 646 → 615 s;
  memcap's peak 12,700 → 13,018 MiB, run-to-run noise against a 4 MB
  cache.

So the weak shared index the pass proposed is not the fix — a weak map
drops an index when its test drops it, and would share less than the FIFO
did. The fix is one bound removed, with
`the_cache_is_bounded_by_bytes_not_by_entries` (forty tiny captures, the
first still shared), which fails with the 32-entry bound restored.

Modules: `crates/rondata/src/capture/indexed.rs` (the bound, the
`RON_INDEX_STATS` count, a test).
