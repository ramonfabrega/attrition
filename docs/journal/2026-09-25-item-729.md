## The cause

`frame_attacked` has two writers in the export:

- `Army::find_target`, which this crate carried;
- **`Object::take_damage@00652020:67-71`**, which this crate did not. At
  difficulty below 2, a non-attrition hit stamps the *struck object's
  owner*.

The spec lines each named the first writer only:

- `ai.rs`'s doc comment on the field;
- ARMY §12's "since I last took a target against `L`";
- COMBAT §7.2 step 3, "(AI, on low difficulty)". This one did name the
  stamp, but gave it the wrong owner, and nothing carried it.

All three are amended in place.
