## What is settled

- **Great Sahara's group patterns.** `init_terrain_data@006a6540` maps
  pattern strings to numbers through the string table: `player` 0,
  `continent` 1, `world` 2, `nonplayer` 3, `corner` 4. `SAHARA.xml`'s 11
  groups use patterns 1, 0 and **2**: "general trees" and "sprinkling of
  oasis" are both `world`. Pattern 4 places nothing, because the jump table at
  0x6a9380 has four entries. The style file's groups **replace**
  `default.xml`'s: there is one `init_terrain_data` call, and it starts with
  `clean`.
- **The no-float note.** The pattern-2/3 weighting runs only when
  `clumps > 6 && regions < 6`. The listing (0x6a7e24..0x6a7f29) is all single
  precision: `cvtdq2ps`, an `addss` sum in list order, `divss` then `mulss`
  per region, and `cvttss2si`. Each step is correctly rounded, so
  `sim::single` reproduces it exactly under DECISIONS 19. The port uses it.
  On Great Sahara there is one region (`c == T`), so the weight is `n`
  exactly. Only the sprinkling group (n = 20) enters the branch. That group's
  list is 21 nodes, and the start draw is `45031 % 21`.
- **The sub-pass falsifier is the draw-site trace, not the dumps.** No dump
  prints `TerrainGroups.cpp`'s detail-5 checkpoints, so 7859 is the only
  checkpoint inside `place_all`. However, **all 280 Great Sahara
  `rontrace-runN.log` files carry the setup path whole**, each draw with its
  return-address site and word. 267 of them are the 2-player run (1,238
  draws) and 13 the 3-player run (1,324), matching §2's counts. So the check
  is draw for draw by site (`rondata::mapgen::setup_draws`, built). Every
  port draw is tagged with the original's return address (`terrain_groups::site`).
- **Part 6 is checkable.** It is `tdata` (240×240 tiles × 2 bytes) plus three
  fog arrays of `4·xs·ys` bytes. That is 158,400 zero bytes at 7854
  (≡ 27,358 mod 65,521, which is why 7854 prints `27358·65536 + 1`).
  `place_all` writes the masks: forest and mountain tiles go through
  `World::set_blocked_at`, which also moves part 5's `blocked`/`bad`/`solid`.
