no game-wide counter, since only the order among standing links matters). `Sim::city_links` sorts by the stamp, and
the sort is stable, so equal stamps (a test's hand-set link) keep the old order. Membership is untouched. The other
reader, `close_city_caravans` (`City::close`'s repath walk over `vans`), now walks theirs' order too.
