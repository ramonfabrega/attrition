The listing, `005fb44c`–`005fb474`: `UVar17` is `CHAR_DEFAULT` when
`local_30 == 0`, `local_34 == 0` and `cmpl $0x1, 0xd8(%ebx); jg` falls
through. `+0xd8` is `OrderList`'s length (`docs/ORDERS.md`:274). The
request carries a third argument, so it rolls.

`seams.py --item 1500 --field cur_anim` named the arm at once. It was a
`SEAM` in `Sim::unit_step`, which called it unreachable because `do_move`'s
"already there" test takes the case a step earlier, and `docs/ANIM.md` §4.9
said the same. That holds for an order to the spot a unit stands on: the
scratch test showed ours dropping such an order before any step. It does not
hold for a leg whose top waypoint the unit already stands on while it owes a
turn.

`standing.py`: none of run655's 173 standing fields is on `1/79` or on its
step. The ones this crate reads are leader and city census fields: `caras`,
`ter`, `filled`, `ocean`, `dock_tile`, `other_team_terr`, `ally_mask`, and
the like.
