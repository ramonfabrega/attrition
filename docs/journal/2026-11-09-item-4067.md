## What was built

- **`render::figure::posed` and `sample`** (new), from the reading of `HierObj::set_to_time@00536e30` and
  `HierObj::update_transforms@00536c60`.
  - **The key sits inside the rest transform:** `world = parent.world · parent2local · local`, with `parent2local`
    the `.BH3`'s loaded transform, so a vertex goes `v · key · rest · parent`. My first build replaced the rest with
    the key, and the figures came out half height. The citizen's own data settles the order: the calf key carries no
    translation (its bone length is the rest's), and the pelvis key's `(−22.3, −3.2, −0.48)` is `−restᵀ · t_rest`,
    which seats the pelvis on `Bip01` as the clip lifts `Bip01` to the hip.
  - **The trees pair by place** (child with child, sibling with sibling), and a node the clip lacks keeps `local` =
    identity, so it stands at rest.
  - **The keys:** the clock is reduced modulo the node's own clip length. Key `k` is reached at `times[k − 1]` (both
    indices step on once the clock passes the lower time), the quaternions blend component-wise with the far
    hemisphere negated (`Transform<float>::set@00421dc0`, no normalisation), and the translation blends linearly.
    `load_hier`'s key flags only skip blends that change nothing within 0.01 / 0.1, and are not reproduced.
- **`client::world`**: `Mesh` carries the decoded model and each slot's `.BHa`. `anim_ms` gives `cur_time · 200 / 3`
  clamped to the clip (`GuyOut::draw`'s clock, `graphic_dt` 0). `World::pose` and `client --pose` turn posing on;
  it is off by default.
- **Tests**: `figure::tests::an_identity_key_leaves_the_rest_pose`, `the_key_is_applied_inside_the_rest_transform`
  (made to fail: with the order swapped it is red, and it is green restored), `a_node_the_animation_lacks_stands_at_rest`,
  `a_clock_between_two_keys_blends_them`. The client's silhouette test also asserts `RUN1559B_3294_POSED`.
- **Documents**: `docs/RENDERER.md` §3.6 (the client's figures; what is reading-only) and §5.3 (the misses), amended
  in place. `docs/PARKED.md` slot DY renamed for this item, with 4067a filed.
