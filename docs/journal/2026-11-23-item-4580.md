**The counter** (`crates/sim/src/core/seam.rs`):
- `seam!("tag")` names a hook `module::path::tag`.
- `seam!("tag", cond)` enters it only when `cond` holds.
- Without `seam-count` both expand to an empty block, `cond` included. Release code, every checksum, the soak's digest
  and every floor are the code as it stood.
- With the feature, the hook writes a thread-local `BTreeMap` the simulation never reads, and only after a walk calls
  `seam::start()`.
- `playback::score` sets the state: the state being read while ranges are taken, and `frame + 1` before the orders
  and the tick that produce it.
- No float, no dependency.
