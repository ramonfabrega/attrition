The embedded profile is 520 bytes: a matrix and a curve. The parsed tags (scratch `parse_icc_tags.py`):
- red XYZ (0.4964, 0.2287, 0.0067);
- green (0.3021, 0.6947, 0.0610);
- blue (0.1657, 0.0765, 0.7572);
- `para` gamma 1.961 on all three.

The red primary's chromaticity x is 0.678; sRGB's is 0.640, P3's 0.680. So the window was photographed on a
near-P3 display. `screencapture` wrote the window server's match of the frame to that display, and a match into a
wider gamut desaturates every saturated colour. That is 4192b's `0.6 · ours + 45`.
