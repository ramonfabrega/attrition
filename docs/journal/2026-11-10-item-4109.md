# Item 4109 — the units line

The driver's in-session builder, Opus 5.5 (`claude-opus-5-5`), in a worktree of its own, from `06ac0045d`.
No capture: run 1562's stream (`stream-3201.tsv`) and packet, and run1100's stream (`stream-3502.tsv`), were
on disk.

## The order of work

1. **The values first.** A scratch decoder of the stream (`b4109/decode4109.py`, outside git): all 52 units
   of run 1562's frame 91 and all 101 of run1100's frame 5408, every range by name — the `SubObject` header
   and its locals, the 19 `ObjectData` fields, the 49 `UnitData` fields with their two unions, the path stack,
   the order list by type, the figures (the guys line's bytes), the animal record. Then a scratch probe of our
   walk on frame 91 (the checksum tests' own `ours_at_packet`), one candidate value a field from where this
   crate holds it, joined field by field (`b4109/join4109.py`). A probe at the built start (frame 0) and
   frame 2 for the gaia animals' order point.
2. **The sort** (below), each parting or unheld field's writers read in the export.
3. **The port** (`crates/sim/src/checksum/units.rs`), the line test, the floors, then the documents (`docs/CHECKSUM.md` §17; §4, §5, §6, §10 amended; `docs/VISION.md` §2, `docs/ORDERS.md` §3.3).
