## The runner (`crates/rondata/src/free.rs`)

`FreeRunner` holds a `Built` from `diff::build_sim`, an optional order stream and its own frame count:
- `step` applies the stream, then calls `sim.command().tick()`;
- `scene` and `terrain` are `Sim::observe` and `observe_terrain`;
- `run_to` hands each tick's scene to a callback;
- `from_captures` stands it up from a capture's setup block, its siblings and the trace's pasture.

It reads no `Sim` field. The setup door is reached only inside `build_sim`.

**A finding the brief's reading did not expect: a setup-only sibling gives units with no figures.** My first build read
every capture's setup block alone. Frame 0's units then carried `figures: []`. The reason is in
`diff::borrow_from_siblings`: it lends a start dump's guys only when the sibling carries frame seeds, and the seeds
come from the sibling's frames. So `from_captures` reads each sibling through `IndexedCapture::with_replay_initial`.
For a pair's start that is three frame states. It still reads none of the long capture's frames. The runner installs
nothing it is given. RENDERER §2.4's "As built" records this.
