## What the evidence says

The booking's direction held: the draw list already carried both poses in register (4061), and the client dropped
them at `client::world::objects` (`Pose::Foundation { .. } | Pose::Scaffold { .. } => continue`). What each one is
drawn *as* comes from the decompile:

- **The foundation is a sprite.** `WallOut::draw_underlays@006410a0` hands `GraphicPieces::draw@0090b2d0` a chad with
  `gpiece = get_construct_gpiece(..)`, angle 270, and `loc2dx`/`loc2dy` the projected point.
  `get_gpiece_type@009096e0` puts the construct range at type `0xc`, and `draw` sends `0xc` to `draw_build`, the
  building sprite's path (§3.5, `sprite_at`). The slot names `building_graphics.xml`'s `<CONSTRUCTION>` in file
  order. Every slot has a `texture=` with `spritexoff`/`spriteyoff`, and only the dock adds a `model=`.
- **The scaffold is a model.** `GraphicPieces::draw_scaffold@00907420` builds its chad with `sx 3, sy −3, sz 3`.
  `GraphicChad::GraphicChad@008e22f0` defaults to `1, −1, 1`, the guy's mirror, so this is the same mirror at three
  times the size. The chad takes `angle` as the slot's own, with no 180 added (`GuyOut::draw` adds one), and
  `loc = slot offset + (x − h, y − h, z)`. The piece is in the ammo range, type `0xe`, which goes to `draw_ammo`.
  `GraphicPieces::draw` returns before drawing an ammo piece when the scene's `draw_flags.ptr[1]` has its top bit
  clear (parked 4163a). Its `cur_time` comes from the building's clock (`+0x7a`, `graphic_dt`), which only the crane
  plays (`anim="CraneWork0/3/5"`).
